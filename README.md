# Website Pengaduan Mahasiswa

Platform aplikasi berbasis web yang dirancang untuk memudahkan mahasiswa dalam menyampaikan aspirasi, keluh kesah, serta laporan permasalahan yang ada di lingkungan kampus. Sistem ini juga dilengkapi dengan panel khusus bagi admin atau petugas untuk meninjau dan menindaklanjuti setiap aduan yang masuk.

---

## 🚀 Fitur Utama

* **Multi-Level Authentication (Login)**:
  * **Mahasiswa**: Dapat melakukan pendaftaran/masuk untuk membuat laporan pengaduan, melihat riwayat pengaduan, dan mengecek status penanganan.
  * **Admin / Petugas**: Memiliki hak akses khusus untuk memverifikasi, mengelola, mengubah status, serta menanggapi pengaduan yang dikirimkan oleh mahasiswa.
* **Formulir Pengaduan Interaktif**: Mahasiswa dapat menuliskan keluh kesah dan permasalahan seputar kampus secara detail.
* **Unggah Lampiran Gambar**: Mendukung fitur *upload image* sebagai bukti atau dokumentasi pendukung atas permasalahan yang diadukan.
* **Manajemen Status Pengaduan**: Pelacakan status pengaduan (contoh: *Pending*, *Sedang Diproses*, hingga *Selesai*).

---

## 🛠️ Teknologi yang Digunakan

* **Front-end**: HTML, CSS, JavaScript, (Framework CSS opsional seperti Bootstrap/Tailwind)
* **Back-end**: PHP
